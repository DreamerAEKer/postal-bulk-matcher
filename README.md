# ระบบช่วยแจงเลขที่และคำนวณเรทค่าบริการไปรษณีย์รวม (Postal Bulk Posting Matcher)

เว็บแอปพลิเคชันสำหรับช่วยเจ้าหน้าที่รับฝากไปรษณีย์จำนวนมาก (Bulk Posting):
- ระบุหมวดเลขที่พัสดุได้หลายหมวด (`RJ`, `RB`, `RC`, `ED`, `EJ`, `EW`, `PB`, `LP` ฯลฯ)
- คำนวณหลักตรวจสอบ **Check Digit (UPU S10)** อัตโนมัติ เพียงกรอกเลขต้น 8 หลัก และจำนวนชิ้น
- จิ้มเลือกเรทค่าบริการ และคำนวณหาจำนวนชิ้นต่อเรทให้ตรงกับยอดรวมตามใบนำส่ง
- รองรับการล็อกจำนวนชิ้นในเรทที่ทราบแน่ชัด
- วิเคราะห์ข้อสังเกตอัตโนมัติกรณีลูกค้าบวกยอดผิด หรือมีเรทราคาอื่นปนอยู่
- บันทึกข้อมูลอัตโนมัติลงเครื่อง (`LocalStorage`) ป้องกันข้อมูลหายเมื่อเผลอกดรีเฟรช
